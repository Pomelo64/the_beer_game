Beer Game Lab: test runner

For the performance assessment, not for learners. It submits the test diagrams to the same evaluation a learner's submission gets, and scores the results against the key. App version ; test diagrams built in.

Each row is one model. Keys stay in this page's memory and are never saved or sent anywhere but to the provider. Rehearsal needs no key: it reads every diagram exactly as the key says, so you can see a whole run and its report for free.

4. Results

The results file holds every run in full: the reading, the verdicts, the slide texts, each AI call's raw answer, time and tokens, and the settings. Keep it: anyone can re-score it with node score.js results.json, even after the models change.
