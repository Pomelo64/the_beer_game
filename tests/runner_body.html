Beer Game Lab: test runner

For the performance assessment, not for learners. It submits the test diagrams to the same evaluation a learner's submission gets, and marks the results against the answer sheet: the flaws each diagram has, and how each element should be classified. App version ; test diagrams built in.

1. Models

Each row is one model. API keys stay in this page's memory and are never saved or sent anywhere but to the provider. Rehearsal needs no API key: it classifies every element exactly as the answer sheet says, so you can see a whole run and its report for free.

4. Results

The results file holds every run in full: the AI's classification of the elements, what was flagged, the feedback's texts, each AI call's raw answer, time and tokens, and the settings. Keep it: anyone can mark it again with node score.js results.json, against this or a changed answer sheet, even after the models change.
